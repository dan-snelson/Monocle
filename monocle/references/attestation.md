# Report Attestation

## Purpose

How to stamp a report with the attestation block, for SKILL.md Step 5 item 8. Load this file once the score is final and before you write the report. The block records which skill text produced the report and what score it gave. `references/verify-report.md` checks it later.

The attestation is self-asserted text, not a signature. It pins the claims so a checker can compare them with the canonical repository and recompute the score. It can't prove that the run followed the rules. Fill it in honestly, and never edit it after the report is written.

---

### Collect the skill identity

Run this once per report, with `skill_dir` set as in Step 5 item 9:

```bash
skill_dir='…'   # directory containing this SKILL.md
skill_dir=$(cd "$skill_dir" && pwd -P)
repo_root=$(git -C "$skill_dir/.." rev-parse --show-toplevel 2>/dev/null)
skill_commit=unknown skill_ref='copied install' skill_tree=unavailable skill_dirty=unknown
if [[ -n "$repo_root" && "$skill_dir" == "$(cd "$repo_root" && pwd -P)/monocle" ]]; then
  skill_commit=$(git -C "$repo_root" rev-parse HEAD)
  skill_ref=$(git -C "$repo_root" branch --show-current)
  skill_ref=${skill_ref:-detached}
  skill_tree=$(git -C "$repo_root" rev-parse HEAD:monocle)
  if [[ -n "$(git -C "$repo_root" status --porcelain -- monocle)" ]]; then skill_dirty=true; else skill_dirty=false; fi
fi
skill_sha256=$(cd "$skill_dir" && find . -type f ! -name .DS_Store ! -path '*/__pycache__/*' | LC_ALL=C sort |
  while IFS= read -r f; do printf '%s  %s\n' "$(shasum -a 256 < "$f" | cut -d' ' -f1)" "$f"; done |
  shasum -a 256 | cut -d' ' -f1)
printf '%s\n' "commit=$skill_commit" "ref=$skill_ref" "tree=$skill_tree" "dirty=$skill_dirty" "sha256=$skill_sha256"
```

- **Monocle checkout** (the same test as Step 5 item 9): the commit, branch, `monocle/` tree hash, and whether `monocle/` has local edits. post-chat-refine edits count as local edits until they are committed upstream.
- **Copied install:** the commit and tree are unknown. `skill_sha256` still identifies the content, so a checker can match it against canonical history.
- **`skill_sha256`** hashes a manifest of every file in the skill directory: one `<sha256>  ./<path>` line per file, sorted bytewise. `python3 "$skill_dir/scripts/verify_report.py" --manifest "$skill_dir"` prints the same value. Use it when `shasum` is missing.

---

### Write the block

Put the block at the end of the Scope section, after the Scope caveats and before `</details>`. Use a tilde fence:

```markdown
**Attestation:**

~~~text
monocle_attestation: v1
skill_repo: https://github.com/dan-snelson/Monocle
skill_commit: {skill_commit}
skill_ref: {skill_ref}
skill_tree: {skill_tree}
skill_sha256: {skill_sha256}
skill_dirty: {skill_dirty}
target: {Scope table Target value}
target_ref: {Scope table Ref value}
score_raw: {raw score from the Total line, before any clamp}
score_final: {headline score}
score_alt: {alternate score, or none}
band: {headline band word, e.g. Poor}
generated_by: {Scope table Generated by value}
timestamp: {Scope table Date value}
~~~
```

- Copy every value exactly. `target`, `target_ref`, `generated_by`, and `timestamp` repeat the Scope table. `score_raw`, `score_final`, `band`, and `score_alt` repeat the Total and Score lines.
- Pin the footer to the commit: `[Generated by Monocle](https://github.com/dan-snelson/Monocle/tree/{skill_commit})`. When `skill_commit` is `unknown`, keep the plain repository link.
- Never "clean up" the identity. Report `skill_dirty: true` when it is true. A checker treats local edits as non-canonical, and an attestation that hides them is evidence of forgery.
